源码事实（按需查看）

这里像一份代码清单，记录有哪些代码文件、程序可以从哪里启动，以及它们直接引用了什么。它能帮助我们调查项目，但不能单凭这些信息判断代码属于哪个架构模块。

术语说明
Python 模块
一个可以被其他代码引用的 Python 文件或文件夹，像项目里的一个小零件。
入口
程序开始工作的地方，像大楼的入口；命令行工具或 Worker 通常从这里启动。
import
代码直接引用另一个 Python 模块，像在清单上写明“会用到这个零件”。
文件哈希
根据文件内容生成的数字指纹；内容变化时，指纹通常也会变化。
Evidence ID
某条源码证据的稳定编号，方便以后再次找到和核对。
静态分析
只阅读代码文字和结构，不运行程序；因此不能证明真实运行时发生了什么。
技术边界（详细）

自动静态事实不赋予七模块归属，也不证明运行可达或架构协作。动态 import、运行时调用和完整调用图未采集，保持 unknown。范围外文件仅表示未纳入本次扫描，不代表历史、停用或无效。
